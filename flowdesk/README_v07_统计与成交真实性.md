# FlowDesk v0.7 — 数学统计与成交真实性审计

## 核心结论

已直接集成到 **Mac FlowDesk 原工程**，不是独立 X11/X12 产品。软件层面保留 v0.6 研究能力。本版加入交易对手深度约束、数据覆盖审查、跨策略共同交易日随机化检验、运行丢失审计。**无任何已验证盈利策略，绝不自动下单。**

## 为什么以前的报价模型会高估盈利

- 最优卖一只有几股，不意味着你可以用卖一价买进任何规模。
- 盘中每秒几百条盘口信号高度相关，不能当成几百个独立样本。
- 12 条规则同时寻找冠军会产生选择偏差。
- 只审计赚钱的一次运行会造成事后挑选偏差。
- 有买一卖一，并不代表有真实成交、完整全市场 NBBO、借券资格、排队优先权或真实冲击模型。

## 第一层：影子交易的最优档深度约束

`prospective.py` 中冻结的参数：

- 影子名义规模：`SHADOW_NOTIONAL_USD=1000`；影子股数 `max(1, floor(1000 / 模型入场价格))`。
- 开仓与平仓都需要可见最优对手档股数至少为模型股数的 10 倍。开仓无量则记录 `CANCELLED`；平仓无量则记录 `CENSORED`。
- 因 1000 美元是**假定名义规模**，不应随意将结果乘以实际资金；更不表明显示深度一定可成交。旧版 v0.6 的实验按旧协议保留，不会悄悄加上新假设。
- 延迟2–15秒入场、60/300秒退出、额外成本8/20/40bp、最多30bp原始买卖价差保留。做空收益依然缺少可借股及融券费证据。

## 第二层：登记所有运行，检查删除与篡改

从 v0.7 开始，录制创建时写入 `recordings/run_inventory.jsonl`（序列化和串链哈希，包含 shadowExpected），保存运行 ID。审计时，若一个应有前瞻影子目录的运行被删除，则输出 `MISSING_SHADOW_DIRECTORY_NO_GO`。库存文件被改动也报错。

本地哈希不是云端不可变存证：有人同时删除或改写全部原始数据和登记文件时，本地无法独立证伪。历史 v0.6 不含运行登记，不能对之前被删掉的整个文件夹进行追溯认证。

## 第三层：完整覆盖才允许探索性数学检验

运行 `AuditAlpha.command` 或：

```bash
python3 alpha_gate.py --recordings recordings --out research/forward_audits/alpha_gate.json
```

检测全部独立研究运行；先运行冻结协议、哈希串链、原始盘口回调一致性和原始录制 SHA-256 审计。之后：

1. 逐个美东交易日计算真正收到的盘口分钟数，**单日至少2只股票各有120分钟盘口**才算一个较完整的观察日；这仍不足以证明全天完整行情。
2. 初始筛查需 **至少30个合格美东交易日、10个有模型退出的不同股票、400笔有效报价模型退出**，且模型开仓后未完成比例不超过5%。这些是保守的研究门槛，不是统计功效、盈利认证或最优参数。
3. 对每个合格交易日/每一条规则计算一次当日模型退出净bps的平均值。该规则没有模型退出的合格观察日取0，所得为 **day-normalized proxy**，绝非真实组合收益、账户PnL或能直接复利的日收益。
4. 对12条规则同一交易日同步随机符号翻转，并利用最大检验统计量形成**探索性**联合比较调整 p 值，主要避免逐笔伪独立和遗漏其他策略的选择。这里没有验证日收益分布对称假设，p 值不是正式显著性保证。
5. 候选须40bp成本压力下有正平均日代理、调整 p <0.05、出现于至少20个合格日、单日模型退出不能占比超过35%。即使达标，也仅标记**下一阶段研究候选，绝不授权实盘**。

特别强调：影子规则重叠、无成交概率、不同股票不同流动性、缺失数据非随机、完整市场样本、策略多次查看和真正样本外验证仍存在问题。对“30天、400次”做优化以使统计通过，同样构成过拟合。

## 当前实测

在隔离环境使用旧录制 `events.jsonl` 实际重审：`64,420` 条事件、`50,588` 条盘口推送、日盘有效盘口仅 `105` 条，`2` 只股票、`1` 个日盘日期。结果 `NO_GO_INDEPENDENT_SAMPLE`，没有可进行统计认证的新前瞻影子运行。新模型没有把旧事件倒填为未来交易。

## Mac 使用

1. 备份旧 FlowDesk，完整解压本包；将过去 `recordings/` 原样复制到新工程同名目录，不要只挑好的复制。
2. 登录并启动本机 OpenD，双击 `Start.command` 运行只读行情台；在有权限的美股正常交易时段保持采集。
3. 正常 Ctrl+C 结束一次录制（不可直接断电）。运行 `AuditForward.command` 和 `AuditAlpha.command`；审计 JSON 可交给 ChatGPT 深入研究。
4. `ScanMarket.command` 继续扫描当前美股股票目录及批量快照；全市场发现并不表示全部证券拥有持续深度盘口。重点股票盘口订阅仍需在 `watchlist.json` 设定，不要误当全市场 L3 订单流。
5. 如需完整自动化动态候选订阅、真实 broker 成交回报、小资金实盘，请先完成权限、市场数据与风险控制的下一阶段验证。本版本没有交易接口。

离线自检：

```bash
python3 -m unittest discover -s tests -v
python3 bridge.py --offline --no-browser --no-record
python3 alpha_gate.py --recordings ./recordings
```

该工程依赖官方 Moomoo OpenD 与本机 SDK；ChatGPT 不能通过云端的 127.0.0.1 直连你的 Mac。
