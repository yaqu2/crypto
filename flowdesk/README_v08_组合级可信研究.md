# FlowDesk v0.8 · 组合资金与全市场研究证据增强

## 这次改的是你的原 FlowDesk，不是独立新产品

原来的 `bridge.py / runtime.py / prospective.py / multiagent.py / intelligence.py / recorder.py / dashboard.html` 全部保留。v0.8 新增 `portfolio_audit.py`、`market_archive.py`、`AuditPortfolio.command`，并将压力审计接入 `alpha_gate.py`、`market_scan.py`、`dashboard.html`。不包含券商下单调用。当前不允许自动实盘。

## 为什么要改：逐笔模型盈利 ≠ 账户盈利

v0.7 的 12 组信号独立观察，如果同一时刻多个规则看中了同一只股票，若简单累加每组收益，会虚增可投本金。做空缺少借券可用性与费用，实际也可能无法成交。缺少退出报价的交易，模型损益未知，不能删除亏损样本。

### `portfolio_audit.py`：统一影子账户压力检验

- 假设测试账户权益 **$100,000**，最大假想同时总名义敞口 **$10,000**，单笔最多 **$1,200**，最多同时 **10** 笔；同一时刻同标的最多一笔。以上是**压力测试预设值**，非投资建议、非优化仓位。
- 交易只来自已哈希核验的前瞻事件链。再独立检查 `SIGNAL → PAPER_ENTRY → PAPER_EXIT` 的身份、因果延迟、方向、价格、最优档深度及 8/20/40 bp 额外成本。
- 不允许未经核验借券条件的模拟做空进入净收益。遇到同标的多个策略同时占用资金，按协议中固定规则顺序竞争，不能为最大化事后利润重新排序。
- 未完成退出或缺少盘口报价的持仓保留为**未知损益**。只有有记录的出场报价才能贡献*已闭合报价模型损益*；不完整时阻断可信度状态。
- 审计报告明确注明：**没有实际券商成交回报、真正的逐时估值、完整资金曲线和真实回撤**，不能把美元模型损益当成实际账户盈利。
- 组合压力状态自动加入 `alpha_gate.py`，只有资金竞争后仍有优势、并且审计完整的研究候选才可能进入下一研究阶段；即使通过，最终仍为 `NO_GO_REAL_TRADING`。

### `market_archive.py`：全市场扫描不能只选最漂亮的一次

- 每次 `ScanMarket.command` 在原有 `output/market/` 的最新视图之外，新建 `output/market/archive/<id>/`，保留本次目录 CSV、报价 CSV、当次质量报告和对应哈希。
- 追加 `scan_inventory.jsonl` 哈希链，识别扫描目录丢失、报价修改、清单篡改和未登记文件夹。
- 每次扫描仍必须尊重 Moomoo 授权、批量接口限制；**当前股票目录+批量快照不是完整逐订单成交记录，也不是历史时点成分股**。
- 本地哈希链不是独立公证；有权限者整体删除全部文件无法在本地自证存在过。

## Mac 使用

1. **先备份旧 FlowDesk 文件夹**，不要与旧版本同时运行订阅或写同一录制目录。
2. 把本压缩包中的 `FlowDesk` **完整解压**到一个新文件夹。确保本机 Moomoo OpenD 已登录，并且本机端口、行情权限正确。
3. 双击 `Start.command` 启动原网页与前瞻影子实验；数据还没连通时严格显示 NO-GO。
4. 双击 `ScanMarket.command`：执行单次全美股当前目录/快照采集、研究筛选，并登记本地归档。无合法行情权限会正常报告失败。
5. 保持连续采集几个交易日后，双击 `AuditPortfolio.command`（统一资金约束审计），然后双击 `AuditAlpha.command`（包括资金审计、样本日和多策略统计）。
6. 页面新增「组合资金审计」面板；运行审计后刷新页面，展示已闭合**影子报价模型**数据。点击面板中的 JSON 链接可查看完整结果。
7. 如需纯离线检查：`python3 bridge.py --offline --no-record --no-browser`；回归测试：`python3 -m unittest discover -s tests -q`。

## 完整研究门槛

必须先拿到多股票、多日、美股正常开盘时段连续盘口和基准数据 → 验证真实交易所时间戳来源 → 进行预注册样本外筛选 → 校准券商实际成交、滑点、交易限制、借券和冲击 → 经独立审计后才可考虑小规模实盘。历史数据显示目前远未达到。每次研究全程禁止宣称保证赚钱。
