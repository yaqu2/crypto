# FlowDesk v1.6 · 实时订单流研究证据熔断

## 核心改动

本版本继续基于用户上传的 FlowDesk 原工程直接更新 `prospective.py`、`runtime.py`、`forward_report.py`、`bridge.py` 和 `dashboard.html`，保留 OpenD 只读接入、全市场批量扫描、候选观察池、原有规则式多 Agent、分段录制、封存前瞻实验、组合审计及 Mac 双击入口。

**本次修复一项重大实验可信度缺口：** v1.5 的报价模型可能根据入场与退出两次盘口先记下一笔模拟收益，随后才由独立路径审计发现中途长时间没有盘口。v1.6 的实时引擎在事件处理阶段就拒绝跨越不可观测盘口缺口计算盈利，并通过独立时钟监控发现长时间没有新回调的悬空持仓。

### 实现逻辑（只针对反事实影子实验，不是实际委托指令）

- 相邻同标的合格盘口接收间隔 **大于 15 秒**：未完成研究头寸 `CENSORED`，取消待入场研究信号，标记 `UNOBSERVED_BOOK_GAP`；本次恢复回调不能立即重开研究信号。
- 独立的后台时钟监视器每次发布周期检查：有研究头寸但最后盘口超过 **15 秒**，标记 `BOOK_SILENCE_CLOCK_MONITOR`，即使此后再也没有盘口回调，也不会一直伪装研究头寸仍有连续证据。
- 每个研究头寸在持有期间必须能证明 SPY 基准及个股有**近期被接收的实时推送且供应商源时间有效**。任一最新源报价早于当前时间超过 **5 秒**或超前超过 2 秒即删失；不从轮询缓存里补造连续报价。
- 离开标准常规交易时段的研究头寸会被删失。标准日历覆盖规则性休市及提前收盘，不认证临时休市。
- 所有删失和理由保留在已有 SHA-256 哈希串链中，并汇总 `discontinuousBookCensored`、`silentBookCensored`、`quoteProofCensored`、`marketCloseCensored`。删失**不是零亏损**，也不计入已证明获利。
- 前瞻研究冻结协议升级到 **v3**，锁定新增限制和本版研究代码 SHA-256。历史 **v2** 引擎原始文件独立保存在 `legacy_v15/prospective.py`，核验原来的冻结协议时不把 v1.6 代码冒充 v1.5。
- 旧包中自动生成的两份审计结果已移到 `research/archived_v15/`，避免网页首次启动把旧报告显示成新验证结果。

这些 15/5 秒门槛是**保守的研究数据要求**，不是价格预测的最优参数，也不意味着盘口安静一定是数据故障。对不活跃股票可能大量删失，这是有意设置的保守边界。

## Mac 安装

1. 停止旧版 FlowDesk，备份整个旧文件夹，尤其 `recordings/` 和封存试验记录。
2. 将完整 v1.6 ZIP **解压到新文件夹**，不要把 `prospective.py` 单独覆盖进已经冻结的试验目录。
3. 打开并登录 Moomoo OpenD（本机 `127.0.0.1:11111`），保持交易时段运行。
4. 双击 `Start.command`。原网页的“前瞻影子实验”面板会显示新删失原因对应的计数。
5. 常规交易时段结束、录制已正常关闭后，依次运行已有的 `AuditRecorder.command`、`AuditCoverage.command`、`AuditQuotePair.command`、`AuditExecutionPath.command` 和 `AuditAlpha.command`。
6. 如希望看到美股动态候选，使用原有 `ScanMarket.command`，在审核后使用 `ActivateWatchlist.command`。不要直接手动改动已封存的研究观察池。

如有正在运行的 v1.5 或更早版本未来封存试验：**保持旧版代码和目录不变直至原试验完成**，v1.6 应建立新的未来实验。新旧版本的统计数据不要未经分组地合并。

## 本轮实际验收

- 完整 Python 回归及对抗测试：**246 项通过**（236 项基线 + 10 项新测试）。测试只是软件不变量，不是 246 次真实交易。
- 原网页离线 HTTP 测试：页面和状态正常、版本 `1.6.0-live-continuity`、无连接时 `NO_GO_CONNECTION`、未完成新审计时 HTTP 404。
- Dashboard JavaScript 语法、Python 编译检查通过。
- 使用真实旧日志 `/mnt/data/events.jsonl` 和元数据验证：**64,420** 条事件；常规时段盘口推送 **105** 条；在要求个股/基准有先行源报价的口径下 **0** 条符合配对；旧录制 `closed=false`，**NO-GO**。见 `research/v16_旧日志配对报告.json`。
- 没有连接用户 Mac 的 OpenD，没有真实策略盈利验证、模拟账户委托、真实订单或保证收益的证据。

## 下一步进入真正收益研究的必要材料

至少提供多个独立美股交易日的完整、已关闭、无本地丢弃的 **SPY + 动态候选**连续报价、盘口、逐笔，以及真实券商成交回报（前期可仅采用模拟委托验证）。先看分钟覆盖率、最长断流、订阅权限和实际 bid/ask 数据，再开始独立未来样本收益验证。

**项目在任何情况下均不自动发真实订单、不启用杠杆、不宣称已经存在稳定盈利 Alpha。**
