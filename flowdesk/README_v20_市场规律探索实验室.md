# FlowDesk v2.0：市场规律探索实验室（原项目增量升级）

**只读研究；不连接交易 API，不下单，不提供可认证的实盘交易策略。**

本轮研发目标不是“画出看起来很有规律的 K 线”，而是研究**同一规则在多个股票、多日和不同市场环境下是否反复成立，并检验成本和缺失数据是否抹去表面优势**。已对原项目 v1.9 的三次扫描报价研究进行延伸，保留所有原有工作流。

## 前提和数据范围

- `ScanMarket.command` 先获取美国当前上市股票目录与被授权快照，按前代逻辑过滤不可用 OTC 数据；基准 `US.SPY` 通过独立请求采集；扫描历史在 `output/market/archive/` 链式归档。
- 需要**至少三次**处于同一美东常规交易日的有效扫描：A 决定候选，B 为 A 完成 2–300 秒后的第一次入场报价，C 为 A 后 15–45 分钟的第一次退出报价。A、B、C 分别以其记录的源时间核对。
- 信号目前固定为上市股票的正向日内异动（当日涨幅至少 2%、当日累计成交额不低于 200 万美元等）；不是 L3/MBO 或主动成交压力完整建模。
- 如果在 2–300 秒和 15–45 分钟窗口缺少第一次对应扫描，或第一张扫描不合格，**不允许挑选后来的更有利价格**。
- **同一证券同一个美东交易日只保留第一条满足条件的信号**，阻断对同一天的重复筛选。
- 每条模拟案例要求显示买卖盘口价差与数量通过 v1.9 的限制，并计入最优报价穿价交易及 40 bp 额外往返成本。**这是报价情景，不是真实交易可成交净利润。**
- 同期 SPY 价格变化作为市场基准从报告结果中扣除；这不代表建立了真正的 SPY 对冲头寸，更没有扣除对冲费用。

## 三项事先固定的可证伪问题

| 假设 | 检验对象 | 对照/统计单位 |
| --- | --- | --- |
| H1 异动后的延续 | 当天涨幅≥2%的正向异动之后，扣除报价成本和 SPY 变化，均值是否仍>0 | 每日等权观察值，按美东自然周分组 |
| H2 强异动是否更可靠 | 同一日涨幅≥5%的股票减去涨幅 2%–5%的股票，报价超额差是否>0 | 必须在**同一天**同时有两组证据 |
| H3 高成交额是否更可靠 | 同一日成交额≥1000 万美元的股票减去其他合格异动股票，报价超额差是否>0 | 必须在**同一天**同时有两组证据 |

同时报告按 SPY 当日涨跌分开的描述性结果，没有足够样本时不会计算统计显著性。这三项是经济研究假设，**不是确认的市场规律**。

## 反过拟合和完整样本硬门槛

- 事前研究口径固定：每股每日首次、3 个假设、SPY 基准、40 bp 成本。
- 至少 **30 个独立美东观察日、20 只具有结果的不同股票、100 个合格报价情景、8 个不同美东周区块**；至少 **95% 事前选出的信号得到合格结果**；文件归档链也必须通过校验。
- 未完成、缺报价、超宽价差、深度不足的信号不得删除，必须进入拒绝/删失分母。
- 统计方法：先每日等权聚合，再按**周区块均值**进行双侧对称性假设下的单侧 sign-flip 敏感性检验；三项固定假设使用 Holm 校正。最多 16 周用精确枚举，更多周采用固定随机种子的 20,000 次 Monte Carlo，输出对随机化假设敏感的**探索性** p 值。
- 即使通过门槛且 p 值非常小，也只会输出 `EXPLORATORY_PATTERNS_NOT_CERTIFIED`；不是封存未来检验，也**不能授予实盘权限**。必须另外取得真正未见过的未来数据、验证净收益和实际成交。

## Mac 执行步骤

1. 备份现有 `~/Desktop/FlowDesk`，停下 `Start.command`、`ScanMarket.command`，确认没有已冻结进行中的未来实验。 **正在进行的封存实验不要升级。**
2. 按你的当前版本选择 v1.9 → v2.0 安全补丁，或独立解压 v2.0 完整工程到另一个文件夹；不得覆盖旧 `recordings/`、`research/` 和 `output/`。
3. 打开并登录 Moomoo OpenD；在正常美股交易时段以 `bash ScanMarket.command` 分别采集 A、B、C。真实上市股票覆盖率仍由权限和行情新鲜度决定。
4. 运行：

```bash
cd ~/Desktop/FlowDesk
bash StudyExecution.command
bash StudyMarketLaws.command
```

5. 报告在 `output/market/market_law_report.json`，也可通过 FlowDesk 网页的 **“市场规律探索与统计反证”** 链接打开；未生成报告时 HTTP 返回 404。

如果尚没有任何 `archive/scan_inventory.jsonl`，程序会正常生成 `NO_GO_ARCHIVE_INTEGRITY` 的诊断报告，不会使用演示数据代替真实收益。

## 非盈利声明与当前瓶颈

2026-10-15 的隔离环境没有你 Mac 最新的全市场多次扫描归档，因此无从计算真正的全市场规律显著性。旧录制文件只有 AAOI/AAOX 的有限市场数据；X9 早期探索性盘口失衡案例（339 条、2 只股票、2 个日期，主要是隔夜和盘前）在跨买卖价差之后普遍为负，不能当成跨市场稳定规律。必须真正取得更多日期和不同股票数据。

OpenD 可连接不等于盘口源完整；交易所分时、源时间、SIP/NBBO、多场所 MBO、借券、券商回报、资金组合约束等未在本模块得到验证。请不要用本报告作为自动交易授权。方案尽量保持 Python 标准库，无新的外部依赖；旧版 `requirements.txt` 保持不变。
