# FlowDesk v2.1 — 市场规律稳健性与盈利反证

> **只读研究工具；不是自动下单、实盘收益证明或模型收益承诺。** 在原 FlowDesk v2.0 基础上增量升级，不改 Moomoo 采集和已冻结的旧研究协议。

## 本轮新增什么

新 `market_robustness.py` 作为独立的“风险、统计、数据红队”，**不新增策略、不挑冠军**。只使用原 v2.0 `market_quote_stress.py` 已核验的历史归档与 `market_law_lab.py` 事前信号清单，避免未来表现参与选股。

- **区分可观察的绝对收益与相对 SPY 的收益**。股票报价情景即使跑赢 SPY，绝对美元或基点收益仍可能为负；相对收益不是已实施无摩擦的对冲交易。
- **逐美东交易日等权**。同一天反复出现的大量相关信号不能伪装成大量独立盈利日。每只股票当天只保留最早的符合研究条件的候选，即使之后出现更有利的信号也不替换。
- **剔除任意一周的稳健性**。逐一删去一个美东自然周，报告剩余周均值范围；检查是否只有某一周在贡献全部收益。
- **缺失未来报价敏感性**。对所有被事前选中的候选保留分母。缺失报价用 0、-50、-150、-300 bps 做明确标注的*反事实假设*，不称其为真实成交亏损。
- **额外成本压力**。在现有 40 bps 往返成本报价情景上，继续追加 0、20、60 bps，不改变原来的股票选择。
- **区分市场环境**。按事前 SPY 日内涨跌分组列出结果，仅作诊断；不能事后挑最赚钱的市场环境宣称预测能力。
- **周区块 Bootstrap 探索区间**。只有完整性和独立样本门槛通过才计算；不保证在结构突变、非平稳和样本选择下的频率学覆盖率。

所有版本的 `tradeEnabled`、`alphaCertified` 永远为 `false`。即使报告为 `EXPLORATORY_ROBUSTNESS_DIAGNOSTICS_ONLY`，含义也不是可交易 Alpha。

## Mac 使用方法

如已安装 **未经修改的 v2.0**，运行 v2.0→v2.1 安全补丁；否则把 v2.1 完整工程解压到**新的文件夹**，不覆盖旧 `recordings/`、`output/`、`research/`。已有封存研究协议时，不得原地换代码。

先保证 Moomoo OpenD 已登录、原 `ScanMarket.command` 在正常美股时段产生至少三次可核验扫描，并跨多个交易日积累数据：第一次选股票；第二次入场报价（与首扫隔 2–300 秒）；第三次退出报价（与首扫隔 15–45 分钟）。报价源必须按原版本的源时间/买卖盘约束通过。

```bash
cd ~/Desktop/FlowDesk
bash StudyExecution.command
bash StudyMarketLaws.command
bash StudyRobustness.command
```

结果保存 `output/market/market_robustness_report.json`。如果 FlowDesk 的网页 `Start.command` 正在运行，可点击 **“市场规律稳健性/缺失样本压力审计”**，报告不存在时返回 404，不会显示旧的假数据。

单独离线运行、甚至没有任何扫描文件时也能显示 `NO_GO_ARCHIVE_INTEGRITY`，**不使用示例行情填补缺失**。

## 最容易误读的三个数字

- `absoluteQuotedNet40BpsDailyEqualMean`：所有**已观察**报价情景平均基点收益，**不是券商确认的真实净收益**。
- `spyRelativeQuotedNet40BpsDailyEqualMean`：上项扣除同期 SPY 价格变化；即使为正，绝对收益仍可能为负。
- `missingOutcomeSensitivity[-150].equalETDayMeanBps`：假设所有缺失信号均得到 -150bps 的*压力测试场景*，不等于真实亏损。

## 最低证据和真实限制

与 v2.0 一样，本模块需要≥30 个可观察交易日、≥8 个不同周区块、≥20 只不同股票、≥100 条有结果的案例、≥95% 原始候选有后续结果、全归档哈希完整。**这些只是探索性统计门槛，不能认证盈利。** 不同股票价格序列、交易所内外场所、融资融券、SIP NBBO、可得买卖盘、市场冲击、真实订单排队与券商回报尚未在本模块被验证。

当前隔离开发环境不包含你 Mac 新录制的全市场归档。旧 AAOI/AAOX 日志也不符合多日、多股票门槛。因此本轮只交付可复现的稳健性审计工具和合成对抗测试，**没有发现新的、已证实的市场规律或可稳定盈利的交易策略**。
