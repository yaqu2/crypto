# FlowDesk v2.3 — 全市场组合资金与未成交报价压力实验室

本次以 **v2.2 原工程**为基线，继续研发，不启动冻结的未来试验，不触发券商真实下单，也不将展示报价解释成已经成交。

## 为什么需要这轮改进

v1.9 的三次扫描研究已经可以研究单股的 `A` 信号、`B` 延迟卖一报价、`C` 未来买一报价，但**一批股票同时出现机会时，不可能让每个假设都不受限制地使用同一笔钱**。还可能发生两种严重的回测污染：同股同日从多个信号中挑选事后赢家；退出资料缺失时把仓位从资金占用中偷偷删除。

`market_portfolio_stress.py` 使用已经哈希审计的市场扫描归档，从**第一个**合格的个股/日期候选和**第一个**符合时间窗口的后续扫描构造研究意向，并把它们置于统一的资金与时间顺序中研究。

## 固定的假设规则（研发压力测试，不是策略参数建议）

- 假设账户规模：100,000 美元；全账户研究性假定组合同时名义占用最高 5,000 美元。
- 同时最多 5 个假设仓位；单信号预算不超过 1,000 美元；当日新开假设名义金额最高 5,000 美元。
- 只做多，禁止无借券证据的做空。按照 A 已选信号，2–300 秒后第一次满足窗口的 B 扫描观测卖一；15–45 分钟后第一次满足窗口的 C 扫描观测买一。
- 展示最优档数量最多假设参与 10%；价差、时间源、个股与 SPY 同步性及上市股票范围依照先前模块约束，不通过时拒绝或记为未知。
- 只使用先前已完成的**报价情景**评估 8、20、40、80、120 bps 的**额外往返成本**。这些并非真实成交成本的测量结果。
- 新的假设仓位按 B 报价时间顺序竞争一个资金池；同时完成时间相同，先处理新入场再处理退出，避免事先释放资金。
- 当已关闭的报价情景当日 40 bps 损失累计达到 100 美元，**后续假设新开会暂停**。这只是已观察到退出后的回放规则，不是实时盘中止损或可靠熔断。
- **如果 C 没有可验证的买一报价、SPY 未同步或盘口不足**，此前已经获准的假设仓位保持未知资金占用；不会假装强制卖出或假设零损益。
- 不允许拿未来走势决定哪条信号获得资金；同一股票每个 ET 日期仅首次候选有资格被研究，早期失败也不能替换。

## 如何运行

必须在 Moomoo OpenD 已验证、存在完整归档的前提下采集**A/B/C 三次或更多**真实全市场扫描后运行：

```bash
cd /Users/quyang/Desktop/FlowDesk
bash ScanMarket.command   # 交易时段 A
# 根据固定预设间隔，在交易时段分别完成 B 与 C 扫描
bash StudyPortfolioStress.command
```

输出文件：`output/market/market_portfolio_stress.json`。同一网页的“行情覆盖与候选选择审计”新增只读 JSON 入口。

无归档时，正确输出 `NO_GO_ARCHIVE_INTEGRITY`；只录到了 B 而没有 C 则报告被占用的**未知头寸**，不能宣称平仓。已验证文件仍只得到 `EXPLORATORY_CAPITAL_CONSTRAINED_QUOTES_ONLY`，**从不**授权实盘。

## 解释报告

- `firstDailySignals`：按同一股票/交易日只保留第一次候选后的总数。
- `admitted`：假定按已显示卖一成交且符合组合资金限制的研究情景个数，**不是券商已成交数量**。
- `closedQuoteCases`：经过后续买一检查的关闭报价情景数量。
- `censoredOrUnclosed` 和 `unresolvedReservedCapitalUsd`：资料不完整造成的未知假设仓位与保留名义资金占用。
- `closedOnlyQuotePnLByCostUsd`：**仅关闭报价情景**在各额外成本假设下的美元计算值，不能解释为可执行利润、账户净值或整体组合收益。
- `unknownCapitalShockUsd`：未知资金占用在假设 10%、20%、100% 单方向不利变动下的资本暴露；**不是概率预测**。
- `accountProfitKnown`、`wholePortfolioPnlKnown`、`alphaCertified`、`tradeEnabled`：始终 `false`，符合当前证据等级。

## 已知局限与下一步

1. Moomoo 当前权限下的最佳买卖档通常是单一数据源展示报价，可能不是完整 SIP NBBO；10% 最优档参与是假设上限，并不能估计实际队列位置、成交概率或市场冲击。
2. 截止目前没有用户 Mac 上的新鲜全市场归档；本次**本地软件测试不等于真实行情验证**。
3. 没有委托状态（提交/接受/部分成交/拒单/撤单/成交确认）的券商回报，不能声称已校准真实滑点。真实成交校准必须在取得用户明确许可后，以低风险、受控流程进行；本版本仍禁止下单。
4. 本研究没有经济事件排除机制、完整交易所日历和券商公司行为修正，还不能认证 Alpha。
5. 这轮不修改核心实时策略或冻结协议。已有封存实验不得安装补丁至原目录，需复制至新文件夹单独评估。
