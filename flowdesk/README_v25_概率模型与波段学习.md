# FlowDesk v2.5 — 板块波段学习与量化模型竞争（只读）

## 最终技术选择：状态特征 + 正则化基线 + 梯度提升树竞争

- **规则观测层（市场状态）**：只用扫描时点及过去五个交易间隔内的固定篮子、SPY 价格，提取集体卖压、反弹观察、动量、相对强度、下跌广度、离散度及波动率等 16 个特征（以代码 FEATURES 为准）。不是“找到了底部”。
- **概率预测层（可学习）**：事先定义未来三次**对齐交易日快照**后，固定篮子中位数回报 ≥2.5%，且跑赢同期 SPY ≥2.0%，记为 1；否则为 0。它只是可预测事件标签，**不是买入、止损、波段盈亏或真实成交**。
- **四个竞争者**：先验平滑常数基线、L2 正则逻辑回归、强正则浅层直方图提升树、CatBoost（`has_time=True`）。机器学习库是可选依赖，缺少某个模型会明确报告，不冒充模型已训练。
- **候选模型先在过去的选型区间比 Brier Score**。模型相对常数基线的改善不到 1% 就使用基线。再使用完全不重叠的后续**校准区间**做 sigmoid/Platt 校准，最后使用更晚的独立**外层测试区间**报告性能。
- **时序净化**：训练标签的结束时间必须严格早于选型区间；选型标签结束早于校准区间；校准标签结束早于测试区间。所有外层窗口使用日期排序、扩展训练集和 purge/gap。绝不随机打乱时间。测试区间上的赢家排序只可用于探索，不得当作已封存的未来盈利认证。

## 为何不是一上来用大型 Transformer / LSTM / HMM？

目前 Moomoo 可供本模块使用的数据，仅是每天同一美东时钟附近一次已校验的快照，且只观察两组各 4 只手工篮子。**在这种数据量和形态下，复杂序列深度学习的估计方差通常高、容易过拟合**。CatBoost 是合理的非线性候选，但它是否胜出，必须由同口径的未来时间块 Brier/logloss 证明。HMM 可用于扩展状态估计，但这里优先采用可复核的显式状态特征，避免事后平滑信息泄漏。

## 默认最小数据门槛

使用 120 个交易日训练、25 个交易日选型、25 个交易日独立校准、20 个交易日外层测试，三个阶段之间各至少 4 个交易日净化间隔；测试每次前移 20 日。至少需要 3 个合格外层窗口。现实中通常需要**约一整年或更多合格连续归档数据**，且必须有足够正负事件；**不是 6 天就能学会崩跌反弹**。中途缺少基准、股票或交易日时系统会拒绝或剔除该事件，并报告丢失数量，不会捏造填充。

**重要：** 这里的一张快照来自美东大约 15:30，非官方收盘价；收益标签没有“未来期间内先触及哪条价位”的信息，因此**不是三重障碍标签**。当前篮子也是现在固定的 4+4 只股票，不是过去完整的 point-in-time 美股股票池。研究必须逐步接入真实历史、完整时间点股票池、退市股票及事件首次公开时间才能更可信。

## 使用

建议先在 v2.4 未修改工程上安全升级；不存在 `.venv` 或 Mac Python 未安装依赖时，先确认 Python 环境，然后执行：

```bash
cd /Users/quyang/Desktop/FlowDesk
./.venv/bin/python -m pip install -r requirements_ml.txt
bash StudyRegimeModels.command
```

没有足够归档时返回 `NO_GO_ARCHIVE_INTEGRITY` / `NO_GO_TRAINING_DATA_INSUFFICIENT` / `NO_GO_INSUFFICIENT_OUTER_FOLDS`，是预期行为。只读研究报告保存在 `output/research/sector_model_selection.json`，网页入口是 **板块反弹概率模型比较**。

> 这是**模型选型和历史研究工具**，不会推送今日 AAOI 的“可交易反弹概率”，不会真实下单，也不能证明任何盈利。等数据充分后先冻结研究设计，再开展独立未来验证。
