# FlowDesk v1.0 · 工程与真实数据验收

**日期：2026-10-14。性质：只读量化研究工程，不是金融收益保证。**

## 已实现、已运行的代码

完整工程源自用户原 FlowDesk v0.4，逐步集成至 v0.9；本轮修改了 `bridge.py`、`recorder.py`、`runtime.py`、`dashboard.html`、原首读文档，新增 `session_coverage.py`、`audit_daily_coverage.py`、`cohort_lineage.py`、`activate_watchlist.py`、`AuditCoverage.command`、`ActivateWatchlist.command`、`tests/test_v10_feed_cohort.py`。

本轮回归 **133/133 项成功**（包括旧版115项与新增18项）；测试输入大部分为人工合成，只说明工程逻辑可用，**不证明策略盈利**。前端 JavaScript `node --check` 通过。原 `bridge.py` 已用离线模式启动，浏览器主页和状态 HTTP 接口返回200；数据门禁 `NO_GO_CONNECTION`，候选激活接口返回 `NO_ACTIVATION_HISTORY`；未执行覆盖审计时相应报告接口按设计返回404。

## 旧数据的客观结论

对用户现有 145,918,509 字节、64,420 条真实 Moomoo 日志进行了严格 SHA256 和全部事件审计；文件完整性通过，但 `metadata.json` 的 `closed:false` 明确标记为采集过程中导出的一段前缀，而非整次采集正常结束。

日期 2026-10-12（美东）：预计正常盘中390分钟；有效记录健康心跳246个分钟（并非246个确认正常行情分钟），105条合格盘口回调（AAOI、AAOX）；**US.SPY 满足源时间条件的报价分钟：0/390**。合格独立日盘：0。报告 `FlowDesk/research/真实日志_v10_行情覆盖率.json`。

因此研究结论是 `NO_GO_PREFIX_EXPORT`，不存在可认证的真实 Alpha。数据不足并非能证明市场不可盈利。

## 人工批准的动态候选机制

当前美股全市场快照通过覆盖审核和本地归档完整性后，候选排序先生成提案；人工确认 `APPLY` 且软件不运行时才替换下次启动 watchlist，并保留备份、哈希激活记录。运行开始后写出观察池内容 SHA256，后续审计可对照候选进入时间，不能事后仅挑赢家。**本轮未连接用户 Mac OpenD，未真实下载全市场行情，未触发自动轮换订阅。**

## 已知边界

- Moomoo 批量快照不是跨所有美股场所的逐订单 MBO，更不能保证全市场实时流完整。
- 录制心跳、供应商报价时间戳、盘口本机回调分别计量；代码使用常规 NYSE 规则日历，并未囊括所有非例行停市。
- 30日、95%有效报价分钟和90%健康分钟为固定、保守的数据工程门槛，不是显著性、净收益或实盘认证。
- 本机哈希链不能防止有权限的用户整体删除、重写历史。
- 实盘盈利和稳定性仍为 **NO-GO**：没有足够的独立完整交易日和已校准的真实成交/费用数据。

## 下一真实阻断点

用户必须在自己的 Mac 上安装新项目、用本地合法 OpenD 权限运行整段常规交易时段、正常结束并运行 `AuditCoverage.command`。在第一次合格记录之前，切勿拿旧样本选高杠杆实盘策略。
