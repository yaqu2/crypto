# FlowDesk v1.6 · 本轮工程验收报告

**范围**：原 FlowDesk v1.5 的实时影子研究引擎与审计。只评价代码行为、因果完整性和当前已上传真实数据，**不是收益/合规/生产运行的第三方认证**。

## 本轮已确认

- 基线：v1.5 原工程 236 项测试全部通过。
- 发现并修复：持仓期间没有连续新盘口时，旧引擎可以先生成 PAPER_EXIT，之后才靠 v1.5 独立路径审计拒绝。
- 新 v1.6 实时引擎直接删失超过 15 秒的持仓中间盘口缺口，独立后台时钟删失静默中断与个股/基准报价源时间过期的影子交易。
- 研究协议从 v2 到 v3，新增的成本外连续性门槛写入冻结协议；历史 v2 文件原样备份且可独立校验。
- 解决新安装包可能显示过期离线审计报告的问题，历史示例移入 `research/archived_v15`。
- 全套 246 项软件测试通过；静态 JavaScript 检查通过；本地 `bridge.py --offline --no-record --no-browser` HTTP 端到端验收通过，空 OpenD 场景 `NO_GO_CONNECTION`。

## 真实日志分析（对用户先前提供的一份录制，2026-10-12 美东）

- 原始事件 64,420，`closed=false`（未结束的前缀快照）。
- 正常交易时段盘口推送 105，其中 AAOI 54、AAOX 51。
- 日盘报价行 50，其中源时钟合格 15；经先行个股/基准配对的盘口 0。
- 结论 **NO_GO_TRADE_OR_ALPHA_CERTIFICATION**。无法凭这份数据证明任何策略盈利或亏损的长期规律。

## 尚未做到

- 未连接用户 Mac/OpenD 进行行情连续性实机测试；无广覆盖的真实逐订单 MBO；无足量未来交易日或实际成交回报；不能预测或保证正收益。
- 阈值为保守先验而非在独立历史大样本上优化后的最优选择；对流动性稀疏股票可能产生较高删失率。
- 这里的哈希串链是本地防误改证据，非独立时间戳公证/恶意攻击完全防护。

**验收结论：软件质量增强通过；真实 Alpha、自动实盘、杠杆准入一律未通过。**
